Gemini API Key

તમારી પોતાની ફ્રી Google Gemini key વાપરો — AI ને real internet search કરવા માટે જરૂરી. Card નથી જોઈતું, ફ્રી tier પુષ્કળ છે.

Key કેવી રીતે મેળવવી (ફ્રી, 5 મિનિટ)
1️⃣ aistudio.google.com/app/apikey ખોલો
2️⃣ Google (Gmail) થી sign in કરો
3️⃣ "Create API key" દબાવો
4️⃣ Key copy કરો (AIza... થી શરૂ થાય)
5️⃣ ઉપર paste કરીને Save કરો

Hugging Face API Key

Sticker Scanner ના AI-read માટે backup — Gemini quota ખતમ થાય તો આ આપોઆપ વપરાય. ફ્રી, card જરૂરી નથી.

Key કેવી રીતે મેળવવી (ફ્રી)
1️⃣ huggingface.co/settings/tokens ખોલો
2️⃣ "New token" દબાવો
3️⃣ Type: "Inference" પસંદ કરો
4️⃣ Token copy કરો (hf_... થી શરૂ થાય)
5️⃣ ઉપર paste કરીને Save કરો
